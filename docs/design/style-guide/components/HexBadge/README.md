# HexBadge

Oyunun imza şekli: bildirim, seviye ve sayaç rozetleri daire değil altıgendir.

- Kırmızı (`heart`): toplanacak bir şey var. Bir ikonda en fazla bir kırmızı rozet; ekranda aynı anda en fazla üç.
- Altın (`gold`): seviye ("Kümes Sv. 7"), ödül sayısı.
- Yeşil (`cta`): tamamlandı.
- Rakam `display-s`, beyaz, rengin koyu tonuyla konturlu. Üç haneden uzun sayı yazılmaz ("99+").
- Yan ray ikonlarının köşesine, ikonun %35'i boyutunda oturur. Rozet sallanabilir; ikon sallanmaz.
