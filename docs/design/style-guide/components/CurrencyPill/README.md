# CurrencyPill

Üst bardaki kaynak sayacı; ikonu hapın solundan taşar, sağda isteğe bağlı yeşil "+" mağazaya gider.

- Sıra (soldan sağa): profil · **Can** · **Altın** · **Altın Yumurta**. Yumurta, kümes düğmesiyle aynı tarafta (sağ) durur.
- Zemin `panel-deep`, rakam `display-s` beyaz. Can hapının altında zamanlayıcı etiketi (`cream` üzerinde `ink`).
- Uçuş hedefi: kazanılan her kaynak bu ikona uçar; ikon her varışta %15 "punch" yapar, rakam sayarak artar.
- "+" yalnız satın alınabilen kaynakta (Altın, Can). Yumurta yalnız oyunla kazanılır, "+" yok.
