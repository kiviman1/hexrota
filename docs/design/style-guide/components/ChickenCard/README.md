# ChickenCard

Alanın sakinlerini gösteren kart: tavuk, adı, hangi kümes seviyesiyle geldiği ve büyüme aşaması (civciv, piliç, tavuk).

- Tavuklar satın alınmaz; kümes yükseltmeleriyle gelir veya büyür. Kart bir koleksiyon albümüdür, mağaza değil.
- Çerçeve `cream` kart + `rarity-common` kenar; etiket aşamayı yazar. Nadirlik renkleri ileride koleksiyon gelirse kullanılır.
- Henüz gelmemiş sakin: siluet (`panel-deep` dolgu), ad yerine "?", altında hangi seviyeyle geleceği.
- Kartın sanat alanı gökyüzü zeminli; görsel 3D modelden render alınır, kümesteki tavukla birebir aynıdır.
- Seçili kart 1.05 büyür ve tavuk bir kez kanat çırpar.
