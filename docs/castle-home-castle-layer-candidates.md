# Castle layer candidates

These experimental assets were created using the built-in image generation edit tool from `Assets/Hexrota/Resources/CastleHome/Layers/CastleWithoutCharacters.png`. They keep the source's 1076 × 1461 transparent canvas and registration. In a recomposed stack put the three towers behind CastleBody. These are generated interpretations, not lossless pixel extractions: hidden portions have been redrawn. A sampled alpha coverage comparison with the source found 99.86% coverage; mean visible RGB channel difference was 7.98/255, and 2.25% of sampled opaque pixels differed by more than 30/255 per channel. Visually verify seams, cutouts and scale in Unity before assigning them to the production prefab. LeftTower contains the golden flagpole, so do not also render a separate pole in the same place. The source remains the fallback.
