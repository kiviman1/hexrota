# Hexrota mobil Unity aktarımı

Referans, telefonda açılan [Hexrota](https://hexrota.vercel.app/) ve GitHub [main b078da4](https://github.com/kiviman1/hexrota/tree/b078da49a0a1c9632195f13aefefad812e7f92ab). Canlı adresteki `index.html`, `app.js`, `style.css` ve `sw.js` içerikleri satır sonları eşitlendikten sonra bu sürümün `dist/` dosyalarıyla eşleşti. Unity projesi `unity-client/`. Başlangıç sahnesi `Assets/Hexrota/Scenes/FirstPlayable.unity`. Ekranlar Unity UI, tahta ve taşlar aynı Unity sahnesinde çizilir. İlk açılış ve devam etme aynı uygulama oturumuna bağlanır.

## Ekran ve davranış durumu
